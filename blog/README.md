# Publishing a blog post

The English pages in the site root and Ukrainian pages under `uk/` are generated HTML. They work without JavaScript. Edit the sources below and regenerate before publishing.

1. Add an HTML content fragment to `blog/content/<slug>.html`. Keep only the article body. Use H2/H3, paragraphs, lists and figures. Existing `data-i18n` keys are resolved at build time from `js/locales/ua.json`; add Ukrainian translations for every new key. A translation can include simple inline HTML when needed.
2. Add a post to `blog/posts.json`: slug, known publication date, author (`bogdan` or `studio`), cover, and English/Ukrainian title, SEO title, description, summary, kind and cover alt text. Set `long_read: true` for posts that need a table of contents and reading progress. Preserve published slugs. A known month can use `YYYY-MM`; do not invent an exact date.
3. Add image originals and register the original cover path in `blog/posts.json` (step 2) before running `python tools/optimize_blog_images.py --add images/new-post/cover.png`. Repeat `--add` for other new images. This requires Pillow; generated files and their dimensions are recorded in `blog/media.json`. Every registered cover receives a JPEG social preview as well as responsive WebP variants. Run `python tools/optimize_blog_images.py --verify-only` to check the assets and cover previews. Keep original paths in source fragments; the builder inserts responsive WebP variants. Add Ukrainian translations of descriptive image alt text to `blog/image-labels.json`. Large lightbox images load when opened.
4. Run `python tools/build_blog.py`, then `python tests/check_blog.py`.
5. Preview with `python -m http.server 8765 --bind 127.0.0.1` from the repository root. Check EN/UK, 320/390/768/1440 px, keyboard gallery controls, the table of contents and the video state after rejecting cookies.

One article template and one list template generate titles, descriptions, canonical/hreflang, Open Graph, Twitter cards, Article/Breadcrumb schema, author/date/reading-time metadata, related links, blog cards and the sitemap. The static header/footer use the shared `header.html` and `footer.html` fragments. Publication dates come from the manifest; layout changes do not fabricate editorial update dates.

Common appearance and interaction live in `css/news.css`, `css/header.css`, `js/news.js`, `js/reading-progress.js` and `js/particles-bg.js`. Galleries rotate automatically and pause while hovered or focused, in hidden tabs, off screen and while the enlarged viewer is open; rotation resumes when those conditions clear. Reduced motion keeps galleries static. Clickable dots select an image; the frameless viewer supports left/right image-half clicks, keyboard controls and closing by clicking outside the image. Calm background particles move slowly at low brightness, stay static when reduced motion is requested and pause in hidden tabs. Keep analytics/consent configuration in `tools/build_blog.py` consistent with the rest of the site.

Generated HTML, optimized images and manifests are committed with the website. Hosting needs no Python or JavaScript build process. The old `news-template.html` is a noindex pointer to these maintained source templates.
