# Теми сезонних статей

Тема вмикається для окремого допису через `"event_theme": "halloween"` у `blog/posts.json`. Вона автоматично діє в усіх опублікованих мовах цього допису. Сторінки без цього поля не завантажують `css/event-article.css` і не отримують палітру чи прикраси. Спільні CSS і JavaScript сайту змінювати не потрібно.

## Новий івент, наприклад зимовий

1. Скопіюйте об’єкт `halloween` у `blog/event-themes.json` під новим ключем, наприклад `winter`.
2. Вкажіть цей ключ у полі `event_theme` потрібного допису.
3. Змініть кольори й зображення в новій темі. Назви кольорів фіксовані, значення — `#RRGGBB`.
4. Додайте до HTML розділів стабільні точки розташування прикрас, однакові для всіх мов:

```html
<section class="event-section" data-event-slot="activity">
    <h2>Назва активності</h2>
    <p>Текст розділу.</p>
</section>
```

`header` — готова точка біля заголовка статті. Решту назв визначає автор статті: `activity`, `decorations`, `closing` тощо. Збірка повідомить про відсутню точку розташування.

## Палітра

| Поле | Застосування |
| --- | --- |
| `background_start`, `background_middle`, `background_end` | Початок, середина й кінець градієнта |
| `surface`, `surface_hover` | Картки автора, поширення та пов’язаних статей |
| `text`, `muted` | Основний і допоміжний текст |
| `heading` | Заголовок статті та заголовки службових блоків |
| `accent`, `accent_hover` | Заголовки розділів, `<strong>`, звичайні посилання |
| `border` | Обводки й розділювачі |

Кнопки використовують чинний спільний компонент. Перевіряйте читабельність на найсвітлішій ділянці градієнта та на поверхнях карток.

## Прикраси

```json
{
  "image": "images/winter/snowman.png",
  "slot": "activity",
  "side": "left",
  "width": 170,
  "rotate": -8,
  "top": 70
}
```

- `image` — оригінал, зареєстрований у `blog/media.json`. Для оформлення використовується малий WebP зі збереженим альфа-каналом.
- `slot` — `header` або назва `data-event-slot` у HTML статті.
- `side` — `left`, `right` або `center`. Центральна прикраса розміщується в потоці тексту як розділювач.
- `width` — ширина на широкому екрані, 48–320 px; типово 180.
- `rotate` — поворот від −30 до 30 градусів; типово 0.
- `top` — відступ від початку розділу, −40–300 px; типово 0.

На широкому екрані бічні прикраси стоять за межами колонки тексту. На вужчих екранах вони зменшуються й займають місце в потоці, без накладання на текст. Вони не інтерактивні та приховані від читачів екрана. Їх не потрібно додавати до галереї.

## Каруселі та відео

Скріншоти використовують чинну локальну галерею (`screenshots-slider` → `swiper` → `swiper-wrapper` → `swiper-slide`). Зовнішня бібліотека не потрібна. Клавіатурне керування, збільшення зображень і варіант без JavaScript залишаються доступними.

Відео розміщуйте всередині відповідного розділу; для казана це `data-event-slot="activity"`.

## Збірка й перевірка

```text
python tools/optimize_blog_images.py --add images/winter/snowman.png
python tools/build_blog.py --modified-date YYYY-MM-DD
python tests/check_blog.py
python tests/check_event_articles.py
```

Для нових скріншотів додайте українські описи до `blog/image-labels.json`. Після зміни палітри перевірте українську й англійську сторінки на широкому та вузькому екранах. Приберіть `event_theme`, щоб повернути стандартне оформлення статті.
