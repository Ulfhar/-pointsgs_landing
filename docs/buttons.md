# Кнопки Points.GS

Єдине джерело оформлення — `css/buttons.css`. Усі кнопки, зокрема посилання з виглядом кнопки, використовують базовий клас `ui-button` та семантичний варіант. Звичайні текстові й навігаційні посилання залишаються посиланнями.

## Варіанти

| Клас | Застосування |
| --- | --- |
| `ui-button ui-button--primary` | Основна дія: грати, надіслати форму, головне завантаження. Світла бірюзова заливка з темним текстом. |
| `ui-button ui-button--secondary` | Друга дія: подивитися геймплей, завантажити окремий матеріал. Темно-синя заливка зі світлим текстом. |
| `ui-button ui-button--ghost` | Допоміжна дія: розгорнути текст, навігація переглядача. Прозора заливка. |
| `ui-button--compact` | Додатковий модифікатор для допоміжних дій: висота щонайменше 44 px. |
| `ui-button--icon` | Додатковий модифікатор для іконкової кнопки: зона натискання 44 × 44 px, обов’язкова доступна назва. |
| `ui-button ui-button--ghost ui-button--media` | Збільшення зображення: його розмір визначає зображення, без звичайної заливки та відступів. |

## Правила

- Стандартна текстова кнопка має мінімальну висоту 64 px, шрифт Arial 18 px / 600, звичайний міжлітерний інтервал, радіус 14 px та одну обводку 1 px. Сусідні основна й другорядна кнопки використовують ці самі розміри. Компактні та іконкові контролі мають окремі спільні модифікатори.
- Палітра спільна: світла бірюза для основної дії, темно-синя поверхня для другорядної. Кольори, контрастні пари тексту й фону, розміри та тіні визначаються токенами у `buttons.css`. Не перевизначайте їх у CSS окремої сторінки.
- Об’єм створює спільне поєднання стриманого градієнта, м’якого внутрішнього відблиску та розсіяної зовнішньої тіні. Обводка залишається одна, приглушена. Не додавайте золоті канти, вкладені рамки або різкі світні краї. Hover трохи підсилює світло, active м’яко притискає кнопку; усі стани описані лише в спільному компоненті.
- Читабельність важливіша за декор: темний текст на світлій основній кнопці й світлий на темній другорядній. Зберігайте контраст щонайменше 4.5:1 на обох кінцях градієнта; `tests/check_buttons.py` перевіряє ці пари за CSS-токенами. Змінивши палітру, перевірте також hover, вузький екран і довший локалізований напис.
- Play змінює вміст, але використовує той самий основний компонент. Не додавайте особливі шрифти, сторінкові правила або окрему систему тіней для Play.
- CSS сторінки задає розташування, зовнішні відступи, вирівнювання й адаптивну ширину. Поведінкові класи на кшталт `home-contact-submit` зберігаються для JS, але не оформлюють кнопку.
- Контекстні змінні `--button-width`, `--button-min-height`, `--button-padding`, `--button-radius` дозволені для геометрії переглядача й медіа. Змінні кольорів у таких контролах можуть лише прибрати фон/рамку для прозорої зони навігації; не створюйте нову палітру сторінки.
- Для переходу використовуйте `<a href>`, для дії — `<button type="button">`, для надсилання форми — `<button type="submit">`. Не додавайте декоративний JS чи обробники, які замінюють звичайну навігацію.
- Не вимикайте видимий фокус. Спільний компонент підтримує disabled, hover, active, `prefers-reduced-motion`, `forced-colors` і `hidden`.
- Іконки без повторення підпису мають `alt="" aria-hidden="true"`. Кнопкам без видимого тексту потрібен `aria-label`. Для Google Play використовуйте прозорий `images/google-play-icon.svg`: спільний клас `play-cta__icon` зберігає місце 44 × 44 px із символом 24 × 24 px по центру. Іконка прозора, без фону, обводки й тіні, окремих станів або власної зони натискання. Не додавайте обгортку чи сторінкові перевизначення іконки.
- Написи короткі й локалізовані: Play / Грати. У Play-кнопці основний напис 20 px / 700, Google Play — 16 px / 600 другим рядком; обидва вміщуються у спільну висоту 64 px. Текст повністю непрозорий, без тіні та зі звичайним міжлітерним інтервалом. Не перетворюйте текст усередині кнопки на зображення.

## Приклади

```html
<a class="ui-button ui-button--secondary" href="#gameplay">Watch gameplay</a>
<button class="ui-button ui-button--primary" type="submit">Submit</button>
<button class="ui-button ui-button--secondary ui-button--icon"
        type="button" aria-label="Copy link">…</button>

<a class="ui-button ui-button--primary play-cta"
   href="https://play.google.com/store/apps/details?id=comPointsGameForge.FarFarForest"
   target="_blank" rel="noopener noreferrer"
   aria-label="Play Lumen Grove on Google Play">
  <img class="play-cta__icon" src="images/google-play-icon.svg"
       width="24" height="24" alt="" aria-hidden="true">
  <span class="play-cta__copy">
    <span class="play-cta__label">Play</span>
    <span class="play-cta__store">Google Play</span>
  </span>
</a>
```

Блог генерує Play-кнопку через `render_play_cta()` у `tools/build_blog.py`; змінюйте цей рендерер, а не згенеровані HTML-файли. Після змін запустіть генератор, `tests/check_blog.py`, `tests/check_home.py` та перевірки кнопок у `tests/`. Оновіть версії змінених CSS-підключень.
